\section{Association maps}\label{sec:association_maps}
One figure per EDPS workflow, derived from the workflow itself: a column per task, headed by the raw data that
triggers it and the recipe it runs; a row per data item that flows between tasks; an arrow from a task to its
products; a line from a product to every task that consumes it, dashed where EDPS treats the input as optional. The
dashed vertical line separates the infrequent (AIT / monthly) calibrations from the daily ones. The comments at the
top of each generated file list where the workflow and the recipe disagree.
